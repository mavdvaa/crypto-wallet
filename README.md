# Crypto Wallet API

API для управления отслеживаемыми криптовалютами и просмотра истории их цен из CoinMarketCap.

## Требования

- Node.js 18 или новее
- npm
- API key CoinMarketCap

## Установка и запуск

1. Установите зависимости:

   ```powershell
   npm install
   ```

2. Создайте `.env` на основе примера:

   ```powershell
   Copy-Item .env.example .env
   ```

3. В `.env` укажите свой CoinMarketCap API key в `CMC_API_KEY`.

4. Запустите сервер:

   ```powershell
   npm start
   ```

Сервер запустится на `http://localhost:3000`. Порт можно изменить переменной `PORT`.
SQLite-файл создаётся локально; по умолчанию используется `database.db`. Путь можно задать через `DB_PATH`.

## Тесты

Запустите тесты командой:

```powershell
npm test
```

Тесты API и фонового обновления находятся в папке `tests`.

## Авторизация

Сначала зарегистрируйтесь через `POST /register` или войдите через `POST /auth`.
В ответе вернётся пользовательский API key. Для защищённых маршрутов передавайте его так:

```http
Authorization: Bearer <apiKey>
```

Ключ CoinMarketCap используется только сервером и не передаётся клиенту.

## Маршруты API

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/register` | Регистрация и выдача API key |
| `POST` | `/auth` | Вход и выдача API key |
| `GET` | `/wallet` | Получение списка монет пользователя |
| `POST` | `/wallet/add` | Добавление монеты |
| `PUT` | `/wallet/update` | Изменение монеты |
| `DELETE` | `/wallet/delete` | Удаление монеты |
| `GET` | `/priceStory` | Получение истории цен выбранной монеты |

Кроме регистрации и входа, для маршрутов требуется Bearer API key. Подробные схемы запросов и ответов описаны в [openapi.yaml](./openapi.yaml).

Для `/priceStory` текущая реализация принимает `crypto` и `length` в JSON-теле GET-запроса.

## Фоновое обновление

Сервер периодически получает актуальные цены отслеживаемых монет из CoinMarketCap и сохраняет историю в SQLite. Обновление цен использует USD. При остановке сервера фоновая задача завершается по `SIGINT` или `SIGTERM`.
